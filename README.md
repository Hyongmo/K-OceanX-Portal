# K-OceanX 기업성장 정보포털

여러 기관에 흩어진 지원사업·R&D·행사 정보를 해양·수산·해운·항만·조선(기자재 포함) 기업이 한곳에서 볼 수 있도록 모으는 시험판입니다. GitHub Actions가 정보를 수집하고 정적 웹페이지(GitHub Pages)에서 검색합니다. 공개용 JSON에는 제목, 원문 링크, 기관, 확인된 일정과 신청 조건 요약만 담습니다.

## 화면

- 지원사업 찾기: 두 탭으로 나뉩니다. 두 탭 모두 미선택 시 현재 접수 가능한 모든 공고를 마감 순으로 제시하고, 마감 공고는 맨 아래에 접어 둡니다. 탭마다 고른 값을 따로 기억합니다(같은 브라우저).
  1. 우리 회사(신청 가능한 공고 제시): 우리 회사 정보를 고르면 그 기업이 신청 가능한 모든 공고를 제시합니다. 다른 업종·기술·지역·업력 전용 공고만 빠지고, 제한 없는 공고는 남습니다.
     - 종사업종: 통계청 승인 해양수산업 특수분류(2018) 9대 분류, 중복 선택. 해당 업종 전용 공고와 업종 제한 없는 공고.
     - 관련기술: 해양수산 기술(해양수산과학기술 분류 13대 분류, KIMST 2024 개정)과 혁신기술(중소벤처기업부 12대 신산업, 2026), 중복 선택. 해당 기술 전용 공고와 기술 제한 없는 공고. 기술 전용은 R&D 과제(표시된 기술)와, 신청 대상 문구에 "AI 기업"·"로봇기업"처럼 기술 기업을 적은 지원사업입니다.
     - 소재지: 시·도 중복 선택. 해당 지역 한정 공고와 전국 공고.
     - 업력: 중소기업창업 지원법 기준 예비창업 / 3년 이내(초기창업기업) / 3~7년(창업기업) / 7~10년(신산업 창업 지원 범위) / 10년 이상 중 하나. 업력 조건이 확인된 공고(K-Startup 업력 항목, 신청 대상의 "창업 7년 이내"·"예비창업자" 같은 문구)만 거릅니다. K-Startup의 "7년미만"은 창업 후 7년 미만 전체(3년 이내 포함)로 읽습니다.
     - 지원사업: 이 항목만 선택 종류 공고만 제시합니다.
  2. 특정 공고(선택한 조건에 맞는 공고 제시): 분야(해양수산 전체 + 9대 분류), 기술, 지역, 업력, 지원사업 모두 선택한 것에 해당하는 공고만 제시합니다. 한 항목 안의 여러 선택은 그중 하나라도 맞으면, 여러 항목은 모두 맞아야 남습니다. 지역은 그 지역 한정 공고만(전국 공고 제외), 업력은 그 업력을 대상으로 정한 공고만 남습니다.
  - 지원사업 종류: R&D 과제, 자금·투자, 실증·시험·인프라, 수출·해외진출, 판로·사업화·기술지원, 인재·교육, 창업보육·경영·IP, 기타. 단추마다 공고 수를 붙이며, R&D 과제에는 연구개발 과제 공모·과제제안요구서·기술수요조사·R&D 기획만 셉니다. 제목에 R&D가 있어도 비R&D, 마케팅, 장비 공동활용, 기술이전·거래, 컨설팅, 애로상담, 일터 개선·재직자 훈련 공고는 해당 지원 종류로 분류합니다.
  - 공고마다 지원사업 종류와 대상 표시(예: "수산물 가공 기업 대상", "해양수산 기업 전체", "업종 제한 없음", "부산 기업 대상")를 붙입니다.
- 행사 일정: 교육·설명회·상담회·전시를 개최일 순으로 보여 줍니다.
- 산업·기술 동향: KOTRA 해외시장뉴스, KMI 동향분석, KIMST 연구성과와 KMI 글로벌 공급망 AI 일일 브리핑 링크를 모읍니다. 이 영역만 해양수산 분야 기준으로 선별합니다.
- 지원기관 안내: 수집된 공고를 낸 기관을 지역별로 모아 보여 줍니다.

## 수집 범위

- 지원사업 허브: K-Startup 공고 API(공공데이터포털), 기업마당 지원사업정보 API와 행사정보 API. 접수 중인 공고 전체를 받습니다.
- R&D: IRIS 접수 중 공고 목록(모든 페이지), KIMST 사업공고·공지사항, NIPA, BISTEP, NIA·AI허브, KEIT 과제기획, 전국 TP 통합 목록과 지역 TP 기획 공고.
- 해양·조선 기관: 한국조선해양기자재연구원 사업공고(최근 90일), 전남정보문화산업진흥원 AI어장 공고, 부산국제수산엑스포, Nor-Shipping, KOTRA 글로벌 전시 플랫폼.
- 판정 원칙: 공고를 낸 기관(조직)이 아니라 공고 내용으로 판정합니다. 기관 이름이나 수집처만으로 해양 특화·업종·지역을 정하지 않습니다. 업종·지역·업력·제조기업 여부는 공고 본문(기업마당 사업 요약 전체와 신청 대상 전체, K-Startup 신청 대상 내용과 공고 내용 전체)을 읽어 정하고, 본문이 있으면 제목으로 정하지 않습니다. 제목은 본문이 전혀 없는 공고(일부 수집처)에만 씁니다. 본문 전체는 판정에만 쓰고 공개 자료에는 신청 대상을 줄여 싣습니다. 해양수산 관련 표시(해양수산 기업 전체)는 누구도 빼지 않으므로 제목도 함께 봅니다.
- 대상 판정(`target_rules.py`): 해양 특화 공고와 업종 제한이 없는 공고를 남기고, 소상공인 대상(착한가격업소 포함)·음식점·숙박 대상(맛집 지정, 식품안심업소, 식품위생업소, 민박 등)·어업인 개인 지원·농업인 대상·농업·농식품 대상(신청 대상이 농가·영농법인·농협·농식품·농산물 업체뿐이고 수산·일반 기업이 없는 경우. "(※…제외)" 문구는 빼고 읽음)·개인 대상(제대군인·구직자·대학생 등, 제목에 "기업"이 없는 경우)·다른 업종 한정(제목에 다른 업종 이름이 있거나, 신청 대상이 철강·석유화학·자동차·이차전지·반도체·디스플레이·화장품·바이오헬스·의약·콘텐츠·영상물·방산·항공·우주·섬유 등 해양수산 기업이 속하지 않는 업종으로만 한정된 경우. 조선·식품·기계·금속·뿌리·물류·에너지가 함께 적혀 있거나 벤처·청년창업·주력산업처럼 넓게 열려 있으면 남김)·기업지원이 아닌 공고(채용, 입찰, 용역, 운영기관 모집, 청중평가단, 결과 발표 등)는 제외합니다. 기업지원이 아닌 공고는 모든 수집처에 같은 기준을 적용합니다. 해양 특화가 아니어도 신청할 수 있는 일반 기업지원은 포함합니다. 기업마당 공고는 사업 요약의 신청 대상 줄("☞" 다음)도 함께 읽습니다.
- 지역 판정: 제목의 [지역] 표시, 신청 대상 문구의 "○○ 소재·관내·본사"와 시·군 이름("전국"이나 "타지역 ○○도 가능"이면 전국), 본문 나머지의 "○○ 소재·관내·본사" 순으로 정하고, 본문이 있는데 지역이 없으면 전국으로 봅니다. 본문이 없는 공고만 제목에 나온 지역·시·군 이름(기관 이름 안의 지역은 제외)과 기업마당 해시태그를 씁니다. K-Startup은 공식 지역 항목을 씁니다. 시·군 이름은 전국 156개 시·군 대응표(`collect.CITY_REGIONS`, 이름이 겹치는 고성군·광주시는 제외)로 시·도를 찾습니다. 기관 소재지로는 정하지 않으며, 아무 데도 없으면 기업마당 공고는 전국, 그 밖의 수집처는 "공고문 확인"으로 둡니다.
- 지원사업 종류 판정(`support_taxonomy.py`): 공고 제목에 나온 말을 먼저 보고, 제목에 없으면 기업마당 공식 분야, 그다음 사업 요약·신청 대상 문구 순으로 정합니다. 단 기업마당 공식 분야가 "경영"이면 범위가 넓어 사업 요약·신청 대상 문구를 먼저 보고, 거기에도 없을 때만 경영으로 둡니다.
- 업종·기술 판정(`target_rules.sector_profile`): 대상 업종(9대 분류)은 신청 대상 문구가 정합니다. 신청 대상에 업종이 적혀 있으면 그 업종, "누구나"·"해양수산산업 및 전후방 연관산업"처럼 열려 있으면 제한 없음(해양수산 기업 전체), 업종이 적혀 있지 않을 때만 제목의 업종 이름을 씁니다. "농수산·농축수산·농림수산"의 "수산"은 수산 업종으로 보지 않습니다. 신청 대상이 식품 기업이면 수산물 가공, 조선이 함께 적힌 업종 목록이면 선박 건조·수리 업종으로 봅니다. 제목과 신청 대상 문구에서 관련 해양수산 기술(13대 분류)과 혁신기술(12대 신산업), 해양수산 기업 전체 대상 여부, 제조기업 대상 여부, 분야 무관 R&D 여부, 신청 대상 문구에 적힌 기술 전용 여부(`tech_only`)를 붙입니다. 12대 신산업은 정부 정책 목록이라 바뀌면 함께 고칩니다.
- K-Startup과 기업마당에 같은 공고가 있으면 K-Startup 쪽을 남깁니다.

## 인증키

저장소 Actions Secrets에 다음 값을 등록합니다. 값은 로그와 공개 파일에 남기지 않습니다.

- `KSTARTUP_API_KEY`: 공공데이터포털 '창업진흥원_K-Startup(사업소개,사업공고,콘텐츠 등)_조회서비스'
- `BIZINFO_API_KEY`, `BIZINFO_EVENT_API_KEY`: 기업마당 '활용정보 > 정책정보 개방'의 지원사업정보·행사정보 API
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 네이버 검색 API(공식 공고 후보 탐색용)

Actions에서 K-Startup 또는 기업마당 키가 없으면 수집을 실패 처리합니다. 로컬에서 키 없이 실행하면 K-Startup은 웹 목록을 읽고 기업마당은 건너뜁니다.

## 로컬 실행

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python collect.py
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:8000 을 엽니다. 기존 정보원 점검 결과로 실행하려면 `python collect.py --samples work`를 사용합니다. 이 옵션에는 로컬에 별도로 보관한 점검 응답이 필요합니다.

## GitHub에서 실행

1. Actions에서 **Collect and publish portal**을 선택하고 **Run workflow**를 누릅니다. 선택 없이 실행하면 수집만 하고 **github-pages** 실행 산출물로 결과를 확인할 수 있습니다.
2. 배포할 때는 `publish`를 선택합니다. Pages의 Source는 GitHub Actions로 설정합니다. 모든 수집과 배포는 수동 실행으로 시작합니다.
3. `check_apis`: 기업마당·K-Startup API 응답 건수와 항목 채움 비율만 확인합니다(배포 없음).
4. `check_naver`: 네이버 뉴스·웹문서 검색 API와 공식 공고 후보 탐색을 확인합니다(배포 없음). [네이버 검색 API 특약조건](https://developers.naver.com/products/terms/)에 따라 API 결과는 공개용 JSON이나 Actions 산출물에 포함하지 않습니다.

수집 오류가 발생하면 실행을 실패 처리해 불완전한 데이터로 사이트를 교체하는 일을 막습니다.

## 남은 과제

기업마당 공고의 업력 조건(공고문 본문·첨부에만 있음), 특허 데이터 연계, 지역 지원기관 목록 정리, 첨부 본문 검색, 이력 보관은 후속 작업입니다. 기관 게시판의 수집 범위와 공개 이용조건은 게시 전에 확인해야 합니다.
